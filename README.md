# Dawat-e-Zaika

Catering website for Dawat-e-Zaika, a kitchen serving weddings, parties, and events in Kalyan and Mumbai.

## Pages

- **Home** (`/`) — landing slides, about section, and featured menu
- **About** (`/about`) — story of the kitchen, in Marathi
- **Menu** (`/menu`) — full menu and specials
- **Contact** (`/contactus`) — enquiry form and contact details

## Stack

- React 19
- Vite
- Tailwind CSS 4
- React Router
- Framer Motion
- Swiper

## Setup

```bash
npm install
npm run dev
```

Other scripts:

- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

## Project layout

- `src/pages` — route screens
- `src/components` — navbar, footer, home sections, menu, and contact
- `src/data` — menu content
- `public/images` — logo and other static images
